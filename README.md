# TinH-c - Nền tảng học online

## 🎓 Giới thiệu
Nền tảng học online hiện đại giống Coursera, được xây dựng với TypeScript, React, Node.js và MongoDB.

## ✨ Tính năng chính
- 📚 Quản lý khóa học với video và nội dung
- 👨‍🎓 Theo dõi tiến độ học tập
- 💬 Đánh giá và nhận xét
- 👨‍🏫 Trang giáo viên
- 📷 Gallery học viên
- ⚙️ Admin dashboard đầy đủ
- 🔐 Xác thực JWT
- 🌙 Dark mode
- 📱 Responsive design

## 🛠 Công nghệ
- **Frontend**: React + Vite + TypeScript + TailwindCSS
- **Backend**: Node.js + Express + TypeScript
- **Database**: MongoDB
- **Storage**: Cloudinary
- **Authentication**: JWT

## 📦 Cài đặt

### Backend
```bash
cd server
npm install
npm run dev
```

### Frontend
```bash
cd client
npm install
npm run dev
```

## 🔑 Biến môi trường
Xem file `.env.example` trong mỗi thư mục
